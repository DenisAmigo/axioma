# Axioma

**Axioma** - бэкенд-сервис для переводов между счетами и продажи банковских продуктов.
Пет-проект на Java 21 + Spring Boot, демонстрирующий современный стек для российского финтех-рынка.

> «Axioma» - то, что не требует доказательств. В банке это звучит так: **деньги не теряются - это аксиома.**

---

## О проекте

Сервис моделирует ядро банковской платформы: счета, переводы, леджер, депозиты через банкомат и оформление e-ОСАГО с холдом средств.

Цели проекта:
- Показать владение современным Java-стеком (Spring Boot 4, Java 21, PostgreSQL, Kafka).
- Собрать проект для портфолио

## Домен

### Ядро - переводы между счетами
- Управление клиентами и счетами.
- Перевод между счетами.
- Леджер (журнал проводок) - каждое движение денег фиксируется.
- Идемпотентность переводов.
- Блокировки при конкурентных списаниях.
- Аудит: деньги не удаляются, только компенсируются обратной проводкой.

### Депозиты - эмуляция ATM
- Внесение наличных через эмулятор банкомата.
- Статусная машина: `PENDING → CONFIRMED / FAILED / TIMEOUT`.
- Retry с backoff, circuit breaker.

### e-ОСАГО с холдом и TTL
- Расчёт стоимости у внешнего страховщика.
- Бронь полиса с TTL.
- Холд средств: доступный баланс vs захолдированная сумма.
- Сага: холд → подтверждение → списание → выпуск полиса.

## Как запустить

### Требования
- JDK 21
- Docker Desktop
- Git

### Шаги

```bash
# Клонировать репозиторий
git clone git@github.com:DenisAmigo/axioma.git
cd axioma

# Запустить приложение
./mvnw spring-boot:run
```
Spring Boot сам поднимет PostgreSQL через Docker Compose.
